# Epic-analysis-project-1
🏥 Epic Clinic Data Analysis

A Python project analyzing outpatient throughput and patient satisfaction using mock Epic EHR data.
🛠️ Tech Stack

Python • Pandas • Matplotlib • Seaborn
🔍 Overview

This project processes daily clinic data to calculate patient Length of Stay (LOS) and visualize performance across departments.
📈 Key Findings

    Top Performer: Pediatrics achieved the highest patient satisfaction (94.0 average).

    The "Wait Time" Penalty: Visualizations reveal a steep drop in patient satisfaction when wait times exceed 15-20 minutes, regardless of the actual exam duration.
